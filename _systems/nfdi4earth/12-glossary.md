The PDF has no glossary; the consortium keeps one in its
[online architecture documentation](https://nfdi4earth.pages.rwth-aachen.de/architecture/architecture-docs/glossary/).
Its entries are reproduced here, marked ●, together with the abbreviations used
across these chapters.

| Term | Explanation |
|---|---|
| API | Application Programming Interface ● |
| CES | Customer Effort Score ● |
| CRUD | Basic operations on a digital artefact are create, read, update, and delete ● |
| CSAT | Customer Satisfaction Score ● |
| DFG | Deutsche Forschungsgemeinschaft — the German Research Foundation, which funds NFDI4Earth (project no. 460036893) |
| DOI | A persistent identifier that uniquely identifies objects and aims to be resolvable to access information ● |
| EOSC | European Open Science Cloud |
| ESS | Earth System Sciences |
| FAIR | Findable, Accessible, Interoperable, Reusable — the principles for research data |
| FOSS | Free and Open Source Software |
| Knowledge Hub | The backend service holding all NFDI4Earth metadata as RDF, reachable over a SPARQL API ● |
| Literate programming | A programming approach where code logic is explained in natural language like English, interspersed with code snippets and macros ● |
| Living Handbook | The edited, interlinked collection of web articles about NFDI4Earth, its services and ESS research data ● |
| LHB | Living Handbook |
| LMS | Learning Management System |
| NFDI | Nationale Forschungsdateninfrastruktur — the German National Research Data Infrastructure |
| NPS | Net Promoter Score ● |
| OER | Open Educational Resource |
| PID | Persistent Identifier |
| RDA | Research Data Alliance |
| RDF | Resource Description Framework — the encoding format for all Knowledge Hub metadata |
| RDM | Research Data Management |
| Research products | Broad category encompassing datasets, services, tools, vocabularies, reports, scientific papers, peer reviews, and other scientific outputs ● |
| SOP | Standard Operating Procedure |
| SPARQL | The query language and protocol of the Knowledge Hub's API |
| USN | User Support Network |

● from the consortium's own glossary. The Knowledge Hub and Living Handbook
entries are listed there without a definition; the wording above is taken from
[section 4](../04-solution-strategy/) of this documentation.
