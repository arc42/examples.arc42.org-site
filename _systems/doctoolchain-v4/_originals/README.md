# docToolchain v4 — original arc42 sources

AsciiDoc sources of the arc42 architecture documentation of
[docToolchain](https://doctoolchain.org) version 4, created by
Ralf D. Müller and the docToolchain contributors.

- Taken from the `main-4.x` branch of
  <https://github.com/docToolchain/docToolchain>, path `src/docs/arc42/`
  (chapters, ADRs, models), fetched 2026-08-12.
- Published rendering: <https://doctoolchain.org/docToolchain/v4.0.x/arc42/>
- `images/` holds the diagram PNGs as rendered by the published site; in the
  sources they are inline PlantUML blocks rendered at build time.
- Licence: MIT (see `LICENSE`, copied from the repository root).

The Markdown sections one directory up are a faithful conversion of these
sources into this site's structure; the AsciiDoc here is the authoritative
original.
