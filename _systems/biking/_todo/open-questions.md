# Open questions — biking2 conversion

Notes from converting `_originals/*.adoc` into the twelve published sections.
Not part of the arc42 documentation itself — delete once resolved.

## 1. Appendix "API" was dropped

`_originals/appendix-api.adoc` documents the REST API, but every request/response
example is an `include::` of a Spring REST Docs snippet (`{snippets}/api/bikes/get/...`)
generated by running the Maven build's tests — those files don't exist in a
docs-only checkout of `src/docs`, so there was nothing to convert.

Options:
- Leave it out (current state) — the twelve required sections don't need it.
- I write a short, prose-only endpoint list from the include structure (paths,
  verbs, one line each) without real request/response bodies.
- You point me at a build output (or I build the project myself, with
  `gpsbabel` installed) to generate the real snippets and I convert the full
  appendix.

**Need your input** if you want this appendix at all.

## 2. Three jQAssistant rule includes were silently dropped

- `02-architecture-constraints.md` ← `include::{rules}/conventions_naming.adoc[]`
- `05-building-block-view.md` ← `include::{rules}/structure.adoc[]` and
  `include::{rules}/concepts_structure.adoc[]`

These render jQAssistant-generated rule listings (naming/structure rules,
presumably with pass/fail results) that only exist after running jQAssistant
as part of a build — not present in the docs-only checkout.

**Need your input** only if you have these generated files somewhere and want
their content folded in; otherwise no action needed.

## 3. Subsection headings left unnumbered

I used plain headings (`## Business Context`) rather than arc42-numbered ones
(`## 3.1 Business Context`). The two older imported examples (`mama`, `htmlsc`)
number their subsections; the newest one (`status.arc42.org`) doesn't. I matched
the newer convention. No input needed unless you'd prefer numbered headings for
consistency with `mama`/`htmlsc`.

## 4. Dropped as generic arc42 boilerplate

  this site, none of which carry it either.
- `images/arc42-logo.png` — only used by the section above, so not copied into
  the published `images/`.

No action needed unless you disagree.
