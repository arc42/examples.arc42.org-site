{%- comment -%} The "42" family menu: a small button in the masthead and the popover it opens, listing the sibling sites from _data/family.yml. The family component (meta.arc42.org, wiki/concepts/family-menu.md), copied from docs.arc42.org-site/_includes/family-menu.html. Per the Same-Name Rule it keeps the family class names (`.family-*`, not `.ex-`): the structure is the family's, only the colours are this site's. One addition, and it is this site's own: the panel opens with the spine. The masthead ends in the six-colour device on every page but home, so the sheet that drops from it carries the same edge. It is the existing include, so the segments still come from _data/spine.yml and stay aria-hidden. The "You are on ..." sentence reads its noun from `here_what` in the data file instead of docs' hard-coded "its documentation". Contract with assets/js/family-menu.js: a .family-toggle button whose aria-controls names the panel, and the panel carrying the `hidden` attribute while closed. Without JavaScript the button does nothing. The footer stopped repeating these links on 2026-11-05. Layout contract with the masthead: the panel hangs from the button's right edge, so this is the LAST child of .ex-masthead__tools, a right-aligned group that does not wrap internally. Never a loose item in the wrapping bar row; see the note in _sass/_masthead.scss. {%- endcomment -%}
