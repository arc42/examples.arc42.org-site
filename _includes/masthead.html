{%- comment -%} A real form, not a link: it submits to /search/?q=… so the field still goes somewhere with JavaScript disabled. assets/js/search.js turns it into an ARIA combobox on top of that — filling the panel while typing and binding Cmd/Ctrl-K — and everything the combobox needs is inert without it: the panel stays `hidden`, aria-expanded stays "false". `.arc42-search` is the FAMILY class name, not `.ex-`. arc42.de owns this component and this is the same component: same markup contract, same ARIA roles, same keyboard down to Cmd-Enter for all results. Per the Same-Name Rule a component matching the family spec takes the family name; only the tokens underneath it differ, because this site has no hue. The role/aria-*/data-* attributes are the JS and CSS contract. Do not rename them without changing both files. {%- endcomment -%}
